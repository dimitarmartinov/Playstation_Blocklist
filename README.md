PlayStation PS4 & PS5 Blocklists for AdGuard Home

These blocklists are highly customized and may not be updated regularly. Please keep this in mind when using them and proceed with caution.

There are currently two types of blocklists available:

1. Strict_Offline
   
    Title: Strict Offline
   
     Format: AdGuard Home
   
     Purpose: Blocks firmware updates, game patches, PSN connectivity checks, telemetry, and advertisements while preserving local network functionality.



3. PSN_Safe
   
    Title: PSN_Safe – Firmware, Telemetry & Ads Blocklist
   
    Format: AdGuard Home
   
    Purpose: Blocks system firmware updates, telemetry, and advertisements while maintaining access to PSN, the PlayStation Store, and online multiplayer features. This list was created to accommodate newer jailbreak capabilities that allow compatible consoles to run custom firmware while retaining access to the PlayStation Network (PSN) for online play.
Important: Use this list at your own risk. Connecting a jailbroken console to PSN may result in a permanent account and/or console ban. Proceed with caution, as there is no guarantee against detection or enforcement by Sony.
